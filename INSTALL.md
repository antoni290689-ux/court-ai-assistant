# Инструкция по запуску

## ИИ-помощник по анализу судебных документов

Проект команды **«Чеширские коты»** для хакатона «ИИ-ассистенты для энергетики».

Приложение предназначено для обработки судебных документов, распознавания текста, извлечения необходимых данных и формирования реестра.

---

## 1. Требования

Для запуска необходимы:

- Windows 10/11
- Python 3
- подключение к интернету для первоначальной установки Python-библиотек
- Tesseract OCR с поддержкой русского языка — для распознавания сканированных PDF

---

## 2. Скачать проект

Скачайте репозиторий в формате ZIP и распакуйте архив.

Откройте папку проекта в Visual Studio Code или другом редакторе.

Убедитесь, что в папке находятся:

- `app.py`
- `requirements.txt`
- `README.md`
- `rus.traineddata`

> Важно: после распаковки ZIP внутри может находиться ещё одна папка с проектом. Терминал необходимо открыть именно в той папке, где расположен файл `requirements.txt`.

---

## 3. Создать виртуальное окружение

Откройте терминал в папке проекта и выполните:

```powershell
python -m venv .venv
```

---

## 4. Установить зависимости

Выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Будут автоматически установлены необходимые Python-библиотеки, включая Streamlit, PyPDF, PyMuPDF, Pandas, OpenPyXL и другие компоненты проекта.

---

## 5. Установить Tesseract OCR

Для обработки сканированных PDF необходимо установить **Tesseract OCR**.

После установки Tesseract должен находиться по стандартному пути:

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

Необходимо также наличие русского языкового пакета `rus`.

Файл `rus.traineddata` включён в репозиторий проекта.

> PDF с текстовым слоем и XML могут обрабатываться без OCR. Tesseract используется для документов, в которых текст необходимо распознать с изображения.

---

## 6. Запустить приложение

В терминале из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

После запуска Streamlit откроет приложение в браузере.

Если браузер не открылся автоматически, адрес локального приложения будет указан в терминале, обычно:

```text
http://localhost:8501
```

---

## 7. Проверка работы

В интерфейсе приложения:

1. Откройте раздел **«Загрузка документов»**.
2. Загрузите судебный документ.
3. Нажмите **«Начать анализ»**.
4. Дождитесь завершения обработки.
5. Проверьте извлечённые данные.

Приложение поддерживает обработку PDF и XML, включая пакетную загрузку нескольких документов.

---

## 8. Работа ИИ-модуля

Архитектура приложения предусматривает использование LLM для интеллектуального анализа документов.

API-ключи не хранятся в репозитории из соображений безопасности.

При отсутствии или недоступности внешнего LLM приложение автоматически использует локальный алгоритм анализа и продолжает обработку документов.

Это позволяет запустить и протестировать основной функционал прототипа без передачи секретных API-ключей.

---

## 9. Остановка приложения

Для остановки Streamlit перейдите в терминал и нажмите:

```text
Ctrl + C
```

---

## Возможные проблемы

### Не найден requirements.txt

Убедитесь, что терминал открыт непосредственно в папке, содержащей:

```text
app.py
requirements.txt
README.md
```

### Команда python не найдена

Установите Python и при установке включите параметр **Add Python to PATH**.

### Не работает OCR

Проверьте наличие:

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

и установленного русского языкового пакета.

---

## Быстрый запуск

После установки Python и Tesseract достаточно выполнить в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

После этого приложение будет доступно в браузере по локальному адресу Streamlit.
