# ИИ-помощник по анализу судебных документов

Проект команды «Чеширские коты» для хакатона «ИИ-ассистенты для энергетики».

## О проекте

ИИ-помощник предназначен для автоматизации обработки судебных и исполнительных документов.

Система позволяет загружать документы, распознавать их содержимое, извлекать ключевые сведения и формировать структурированный реестр.

## Основные возможности

- загрузка PDF-документов;
- загрузка XML-документов ФССП;
- OCR-распознавание сканированных документов;
- автоматическое определение типа документа;
- извлечение номера дела;
- определение суда;
- извлечение данных истца и ответчика;
- определение даты документа;
- извлечение сумм задолженности, пени и госпошлины;
- формирование реестра обработанных документов;
- обработка нескольких документов.

## Поддерживаемые форматы

- PDF
- XML
- PNG
- JPG / JPEG

## Используемые технологии

- Python
- Streamlit
- PyMuPDF
- PyPDF
- Tesseract OCR
- Pandas
- GPT-OSS-120B — для интеллектуального анализа текста
- OCR-модель технологического партнёра — для распознавания документов

## Принцип работы

1. Пользователь загружает судебные документы.
2. Из PDF извлекается текст.
3. Если текстовый слой отсутствует или имеет низкое качество, применяется OCR.
4. XML ФССП разбирается по структурированным полям.
5. Из текста документа извлекаются ключевые сведения.
6. Полученные данные отображаются пользователю.
7. Результаты можно добавить в реестр.
8. В случае наличия слов-маркеров данные и документ направляется юристу посредством e-mail.

## Извлекаемые данные

Система определяет:

- тип документа;
- номер дела;
- суд;
- истца;
- ответчика;
- дату документа;
- основной долг;
- пени;
- госпошлину;
- номер исполнительного производства для документов ФССП.
